Micron-Parser-Go

Micron markup to HTML, in Go and WebAssembly.

A fast Micron parser for libraries, services, and the browser. The playground uses the same WASM build that ships in releases.

Get started

Requires Go 1.27.1+. The package uses the standard library only. Add it to your module, then convert Micron source to an HTML fragment:

  1. Import micron-parser-go/micron.
  2. Create a Parser with theme and monospace options.
  3. Call ConvertMicronToHTML with your markup.
Go 
package main

import (
        "fmt"

        "micron-parser-go/micron"
)

func main() {
        p := micron.Parser{
                DarkTheme:      true,
                ForceMonospace: true,
        }
        src := "> Title\n\nHello `!world`! and `*micron`*.\n"
        html := p.ConvertMicronToHTML(src)
        fmt.Print(html)
}

For browsers, load the WASM build and call micronConvert(markup). Try markup live in the playground.

Library and WASM

Import the Go package in your tools, or load the WASM module in the page. Format, colors, links, fields, tables, and partials match Nomad Network Micron behavior.
